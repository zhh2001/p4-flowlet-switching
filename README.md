# p4-flowlet-switching

P4_16/v1model forwarding on a four-switch BMv2 diamond. The current data plane provides static IPv4 routing; stateful flowlet selection is not implemented yet. The Go control plane uses `zhh2001/p4runtime-go-controller` v1.1.1.

```text
             s2
           /    \
          /      \
h1 --- s1          s4 --- h2
          \      /
           \    /
             s3
```

| Link  | Ports      |
| ----- | ---------- |
| h1–s1 | h1:0, s1:1 |
| s1–s2 | s1:2, s2:1 |
| s1–s3 | s1:3, s3:1 |
| s2–s4 | s2:2, s4:2 |
| s3–s4 | s3:2, s4:3 |
| s4–h2 | s4:1, h2:0 |

h1 uses `10.0.1.1/24`, MAC `00:00:00:00:01:01`; h2 uses `10.0.4.1/24`, MAC `00:00:00:00:04:01`. Switch port MACs are `02:00:00:00:<switch>:<port>`, with hexadecimal octets. Switches s1–s4 use device IDs 1–4, P4Runtime ports 50051–50054, and Thrift ports 9091–9094. Permanent host neighbors and static host routes avoid ARP.

Each switch has two host routes. Both directions use s2; s3 has equivalent transit routes. Every routed hop rewrites Ethernet addresses, decrements TTL once, and updates the IPv4 checksum. Host-to-host traffic traverses three routed hops. Transport bytes remain unchanged.

Non-IPv4 packets, invalid IPv4 checksums, options (`IHL != 5`), invalid version, TTL 0/1, truncated IPv4 packets, and route misses are dropped. ICMP, fragments, TCP, and UDP follow the same static routes. Transport headers are not validated by this version. No ICMP errors are generated by the switches.

## Build and run

Prerequisites: Linux, P4 compiler with v1model, BMv2 `simple_switch_grpc` with P4Runtime and Thrift, Mininet 2.3, Python 3.12 or later, Scapy, Go 1.25 or later, GNU Make 4.3 or later, `ip`, `ethtool`, and `ping`. Mininet requires root. The first Go build may download module dependencies and the declared toolchain.

```sh
make build
make run
```

```text
mininet> net
mininet> h1 ping -c 1 10.0.4.1
mininet> exit
```

The controller installs the pipeline and routes through P4Runtime, then compares the complete pipeline, every route, and the default drop action with readback. Readback permits equivalent padded integer encodings and entry ordering, but rejects missing, extra, duplicate, or different entries. While the topology is running, verification can be repeated without pipeline or table writes:

```sh
build/controller --device 1 --verify-only
```

Readiness uses listener checks followed by P4Runtime arbitration and verified configuration. Runtime logs live in a temporary directory removed at shutdown. Existing interfaces or occupied control ports cause startup to fail. Cleanup uses owned child processes and Mininet links; it does not run global `mn -c` or kill other switches. Mininet's global sysctl tuning is disabled.

## Tests

```sh
make test
make clean
```

Tests compile P4 with `--Werror`, inspect the compiler output, exercise controller construction and exact readback, and run real BMv2 switches in Mininet. Raw AF_PACKET sockets are bound before injection. Captures verify exact packet counts on both branches, both transit exits, and the destination host, including MAC rewrites, per-hop TTL, IPv4 and transport checksums, and unchanged payloads. Lower-path forwarding is tested by configuring the edge routes through P4Runtime (`--static-path 1`) and then injecting from the hosts. Both nonzero and zero UDP checksums are covered. TCP probes use RST/ACK so the destination kernel does not generate a reply.

The suite also checks IPv4 validation and route-miss drops, ping, live `--verify-only`, normal cleanup, and cleanup after controller configuration fails. Captures stay in memory. Build products live under `build/`; `make clean` removes them and local Python caches.
